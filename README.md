# Attendance and Marks Planner

I built this as a simple student utility. It has two separate calculators: one for checking attendance and another for estimating the average marks needed in the remaining exams.

## Attendance calculator

Enter the number of classes conducted, the number attended and the attendance percentage required by your college. The result shows the current attendance and, where possible, how many more classes you need to attend or how many classes you can miss.

## Marks planner

Enter the number of completed and remaining exams, your current average and your target average. The tool estimates the average required across the remaining exams, assuming every exam has equal weight.

## Run it

No installation is needed. Open `index.html` in a modern browser. The calculations run locally using JavaScript; there is no backend and no data is uploaded.

## Built with

HTML, CSS and vanilla JavaScript.

## Please keep in mind

The marks planner calculates a simple average. It does not calculate an official CGPA because colleges may use credits, grade points, different subject weights, labs and other rules. Check your college's regulations before making academic decisions based on the estimate.
